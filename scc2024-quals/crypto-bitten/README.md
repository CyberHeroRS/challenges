# Bitten

**Author** : Lofer  
**Difficulty** : <font color='green'>Easy</font>  
**Description**: 
A few bits here, a few there- what could go wrong? 

**Flag**: `SCC{kronecker_or_legrenge_or_jacobi}`

## Solution

Notice that the Jacobi symbol of `g` in regard to `p` is -1. As a result, the Jacobi symbol of an output determines whether it was a 1 or a 0 bit.
