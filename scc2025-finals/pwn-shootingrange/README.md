# Shooting range [PWN]

Stack challenge where you need to first leak and then predict the cstdlib RNG to correctly overwrite GOT addresses in the memory. After that you need to trigger an overwritten function on GOT to get a shell. Solve script is available in the repository and contains the more detailed comments for each step.
